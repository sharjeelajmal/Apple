# Rules

- Write production-ready, clean, and human-like code.
- Keep the code simple, readable, and maintainable.
- Never add comments unless requested.
- Use reusable components for every section.
- Avoid duplicate code (DRY).
- Use meaningful file, component, function, and variable names.
- Keep components small and focused on a single responsibility.
- Move repeated logic into reusable components or utilities.
- Keep pages clean by composing components.

# Global CSS

- Define all colors, font families, font sizes, font weights, spacing, border radius, shadows, transitions, and other design tokens in `globals.css`.
- Avoid hardcoding styles inside components whenever possible.
- Reuse CSS variables throughout the project.

# Responsive

- Mobile-first approach.
- Ensure every section works perfectly on all screen sizes.

# Code Style

- Follow modern React and Next.js best practices.
- Prefer clean JSX with proper formatting.
- Keep the folder structure organized and scalable.
- The final code should look like it was written by an experienced frontend developer, not AI.
